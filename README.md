# 🌦️ Advanced Weather App

A feature-rich, modern, and interactive Weather Web Application built with **HTML5**, **CSS3**, and **JavaScript (ES6+)**. The application features a sleek **Glassmorphism UI design**, real-time weather data fetching, GPS location tracking, and dynamic 5-day forecasts.

🚀 **Live Demo:** [https://gb376052-cpu.github.io/Weather-App/](https://gb376052-cpu.github.io/Weather-App/)

---

## ✨ Key Features

* **🌍 Global Search:** Get instant, real-time weather updates for any city worldwide.
* **📍 Geolocation Detection:** Fetch current local weather data with a single click using your browser's GPS.
* **🌡️ Temperature Unit Toggle (°C / °F):** Seamlessly switch between Celsius and Fahrenheit.
* **📊 Comprehensive Metrics:** Displays detailed metrics including *Feels Like* temperature, humidity percentage, wind speed, and atmospheric pressure.
* **📅 5-Day Forecast:** Interactive forecast cards displaying weather conditions for the next 5 days.
* **💾 Recent Search History:** Saves recently searched cities locally using `localStorage` for fast access.
* **🎨 Glassmorphism UI:** Aesthetic translucent frosted-glass card design overlaid on a custom background (`bg2.jpg`).

---

## 🛠️ Built With

* **HTML5** – Web page markup and structure.
* **CSS3** – Custom styling, Flexbox/Grid layouts, backdrop blur effects, and responsive design.
* **JavaScript (ES6+)** – Asynchronous API calls (`async/await`), DOM manipulation, and local storage handling.
* **API Data** – Powered by `wttr.in` weather service.
* **Icons** – FontAwesome 6 & OpenWeatherMap icon assets.
