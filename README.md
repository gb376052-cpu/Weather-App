# 🌤️ Weather App

A modern and interactive Weather Application built using HTML, CSS, and JavaScript. This app allows users to check real-time weather details, temperatures, and conditions for different locations with a clean user interface.

## ✨ Features
* Real-time weather data fetching.
* Clean, minimalist, and responsive user interface for both desktop and mobile screens.
* Easy-to-use search functionality to check weather conditions for any city.

## 🛠️ Tech Stack
* **HTML5**: Markup and structure of the app.
* **CSS3**: Styling, layout, and visual design.
* **JavaScript (ES6)**: API handling, DOM manipulation, and app logic.
